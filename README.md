# 8ubah Discord

مشروع يبني دايلب (`8ubahDiscord.dylib`) ويحقنه في ipa الدسكورد (النسخة 329.0 المفكوكة).

## اللي فيه
- مايك: مغيّر الصوت، مضخم، صدى، اسمع صوتي، سكر صوتي
- ستيريو: تشغيل ملف صوت/فيديو عبر المايك
- العوازل مطفية نهائيا (بدون مفتاح):
  - النظام: وضع الجلسة + VPIO + AGC
  - محرك الدسكورد نفسه: Krisp + الصدى + الضجيج + AGC (عبر `setTransportOptions:` في VoiceEngine)
- الخلفيات: صورة / لون / تدرج / تمويه / تعتيم لشاشة الدردشة
- رسائل سريعة: ارسال رسالة بضغطة، وتكرار (أقل فاصل 2 ثانية)
- تشخيص: تقارير تطلع مسارات الدردشة والصوت من التطبيق نفسه

## البناء
1. ارفع المجلد كله على GitHub (repo جديد).
2. تبويب Actions ← build-dylib ← Run workflow (أو أي push).
3. حمّل الـ artifact `8ubahDiscord` وفك الضغط ← `8ubahDiscord.dylib`.
4. على ويندوز:
   `py tools\build_ipa.py "C:\...\Discord_329.0_xxxxx.ipa" "C:\...\8ubahDiscord.dylib"`
   يطلع `Discord_329.0_xxxxx-8ubah.ipa` جنب الملف الأصلي.
5. ثبّته بـ Sideloadly.

## أخذ المسارات (التشخيص)
داخل التطبيق: الزر العائم ← تبويب «تشخيص»:
- «تقرير كامل» يفتح Share ← احفظه وارسله لي
- بعد ما تدخل شات وتدخل روم صوت، اطلع التقرير مرة ثانية

بدون تثبيت (من الملف مباشرة):
`py tools\scan_ipa.py "Discord.ipa" voice audio chat input send compose krisp`
يكتب `scan-result.txt`.
